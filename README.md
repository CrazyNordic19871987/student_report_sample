# Персональный отчёт ученика — ONE! City

Образец персонального отчёта ученика по итогам смены **«ONE! City»**: карта талантов и оценка навыков на примере «Жанны Кармановой».

## О проекте

Проект представляет собой пример индивидуального отчёта участника смены **«ONE! City»**. Отчёт показывает результаты и развитие ученика в интерактивном формате: карта талантов, оценка навыков (DISC-профиль, компетенции, IT-навыки), учебные проекты и профориентация.

Документ оформлен как серия слайдов, что делает итоги смены наглядными и удобными для демонстрации родителям и участникам.

## Как открыть

Откройте файл `index.html` в современном браузере (Chrome, Firefox, Edge). Отчёт работает локально, без установки сервера. Кнопка печати позволяет сохранить отчёт в PDF.

## Стек

- **HTML** — разметка слайдов отчёта;
- **CSS** — оформление, тёмная тема, адаптивная вёрстка;
- **JavaScript** — интерактивные элементы, случайные факты, модальные окна;
- **Ассеты** — `avatar.png` (фото ученика) и `logo.png` (логотип проекта).
